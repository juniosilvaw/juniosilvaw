## 👋 Sobre mim

Sou **Anderson J C Silva**, estudante de **Engenharia de Software** e **Desenvolvedor Full Stack em formação**.

Estou construindo minha base em desenvolvimento de software através de estudos, projetos práticos e experimentação com diferentes tecnologias.

Meu objetivo não é apenas aprender uma linguagem ou framework, mas entender como as diferentes partes de um sistema se conectam — da lógica e programação ao banco de dados, APIs, aplicações web, infraestrutura e segurança.

> **"Não quero apenas aprender a programar. Quero aprender a construir software."**

Atualmente, meus estudos estão concentrados principalmente em:

- 💻 Programação e lógica
- 🌐 Desenvolvimento Web
- ⚙️ Desenvolvimento Full Stack
- 🗄️ Banco de dados
- 🔌 APIs e integração entre sistemas
- 🔐 Fundamentos de segurança
- 🌐 Redes de computadores
- 🐧 Linux e sistemas
- 🔧 Git e GitHub
- ☁️ DevOps e infraestrutura
- 🤖 Ferramentas e aplicações de Inteligência Artificial
