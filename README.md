## Sobre mim

Sou **Anderson J C Silva**, estudante de Engenharia de Software e desenvolvedor Full Stack em formação.

Estou construindo minha base em desenvolvimento de software por meio dos estudos, da prática e da criação de projetos.

Quero entender não apenas como escrever código, mas também como transformar uma ideia em uma aplicação, organizar sua estrutura, trabalhar com dados e compreender as tecnologias envolvidas no desenvolvimento de sistemas.

Neste perfil, compartilho projetos, experimentos e parte da minha evolução na programação.

> Aprender tecnologia é o processo. Construir software é o objetivo.

## Minha trilha de aprendizado

Quero evoluir de forma progressiva, fortalecendo os fundamentos antes de avançar para arquiteturas e ferramentas mais complexas.

1. Lógica de programação e algoritmos.
2. Fundamentos das linguagens de programação.
3. HTML, CSS e JavaScript.
4. Git e GitHub.
5. Banco de dados e SQL.
6. APIs e desenvolvimento back-end.
7. React e Node.js.
8. TypeScript.
9. Linux e Docker.
10. CI/CD.
11. Cloud e DevOps.
